## 🚀 Current Focus

### ExamPrepNexus

A scalable, multi-exam preparation platform being designed for students preparing for state-level competitive examinations.

The platform follows an **API-first and exam-centric architecture** with a reusable canonical question bank.

**Core capabilities under development:**

* State and exam-based academic structures
* Subjects, chapters, topics and lessons
* Canonical reusable question bank
* Previous Year Papers, mock tests and practice assessments
* Role-based administration
* Student progress and performance tracking
* Subscription and access-control architecture
* Personalised preparation journeys

**Technology stack:**

`NestJS` · `TypeScript` · `Prisma` · `PostgreSQL` · `Nuxt.js` · `Vue.js` · `Tailwind CSS`

> This project represents my transition from conventional full-stack development toward product architecture and scalable platform engineering.
